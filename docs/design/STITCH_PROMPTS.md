# Google Stitch Generation Prompts

## Synced Android — master prompt
Design a modern, bright Android personal and shared finance app called **Synced**, a TukuTuku Innovation Labs product. Synced is a backend-first financial intelligence engine whose Android client helps individuals, couples and families understand income, spending, bills, plans and shared savings “Baskets”. The app can securely detect financial SMS from mobile money, banks and utilities, stage or import transactions, identify recurring bills, detect trends and explain what is likely to happen next.

Use a light-first visual system: warm white/cool neutral canvas, crisp white cards, dark navy text, blue primary actions, fresh green positive states, violet for Baskets/shared planning, amber for attention and coral only for expense/risk. Avoid dark dashboards, black surfaces, neon, heavy gradients, glassmorphism and crypto aesthetics. Use generous whitespace, 16–20px radii, clear 8px spacing rhythm, modern sans-serif typography, accessible contrast, subtle borders and minimal shadows.

Primary tabs: Home, Activity, Plan, Baskets, More. Secondary screens: Insights, Shared Space, SMS Sync/Review Imports, Bills, Transaction Detail, Basket Detail, Plan Editor, Settings/Privacy, Account Linking.

Home must show: available this month, income/spend summary, plan progress, next bill, one grounded “Synced insight”, basket progress, recent activity, SMS sync status. Every screen must include empty/loading/error/offline states and realistic UGX data. Design for Ugandan users first but keep currency/country extensible.

The experience should feel like a high-quality financial planning tool: optimistic, trustworthy, calm and practical. Do not make every card colorful. Use semantic color only where it communicates meaning.

## Missing Tuku product frontend baseline
For any Tuku product lacking an adequate frontend, generate a production SaaS/application interface rather than a marketing mockup. Begin by defining the user goal and one primary action per screen. Use reusable patterns, semantic tokens, real data states, responsive desktop/tablet/mobile layouts, strong typography hierarchy, calm surfaces, accessible controls, restrained accents, skeleton loading, empty states and actionable errors. Preserve each product’s personality rather than copying ECITAA or Synced verbatim. Tuku family resemblance comes from spacing, typography discipline, navigation behavior, data clarity, state handling and component quality—not identical colors.
